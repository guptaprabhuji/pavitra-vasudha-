1. बदबू (खट्टी या सड़ी गंध) आ रही है:

कारण: अतिरिक्त नमी या ऑक्सीजन की कमी। उपाय: एक कटोरी सूखे पत्ते, लकड़ी का बुरादा या कोकोपीट मिलाएं और मटके को लकड़ी से अच्छी तरह हिलाएं।

2. छोटे कीड़े (Fruit Flies) दिख रहे हैं:

कारण: गीले कचरे की ऊपरी सतह खुली रहना। उपाय: मटके के ऊपर हमेशा 1 इंच सूखी मिट्टी या सूखे पत्तों की परत से ढक कर रखें।
